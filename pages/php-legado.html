PHP Legado: os gargalos que moldaram o futuro

Um mergulho honesto nas limitações que fizeram o PHP ser mal visto por tantos anos — e como o PHP 7.0 corrigiu cada uma delas com exemplos práticos.

Voltar ao início

O que era o "PHP legado"?

PHP 4.x e 5.x — o que sustentou a web por mais de uma década.

Entre 2000 e 2015, o PHP foi a espinha dorsal da web. Blogs, e-commerces, fóruns, WordPress, Joomla, Magento — praticamente tudo era PHP. Mas a linguagem carregava vícios de design que tornavam o código difícil de manter em projetos grandes.

Gargalos técnicos

Os principais problemas do PHP antigo

Performance

Cada requisição recompilava o script. Sem OPcache amplamente adotado, frameworks como Symfony 1 e Zend Framework eram lentos e consumiam muita RAM.

Tipagem fraca

Sem type hints escalares, bugs silenciosos eram comuns. "10" + "20" funcionava, mas escondia erros.

Erros silenciosos

Funções retornavam false em vez de lançar exceções — causando bugs difíceis de rastrear.

Sintaxe verbosa

Sem null coalescing, arrow functions, match — o código era cheio de isset() e ternários aninhados.

Segurança

mysql_query(), register_globals, magic_quotes — recursos inseguros que causaram milhares de vulnerabilidades.

Ecossistema fragmentado

PEAR, PECL, Composer pré-1.0 — difícil gerenciar dependências e padronizar projetos.

OOP inconsistente

Classes com sintaxe confusa, ausência de traits, tipagem fraca em herança.

Data/hora problemáticas

Uso massivo de date() e strtotime() com bugs de timezone. Sem DateTimeImmutable.

Comparativo

Antes × Depois

Veja como o mesmo código era escrito no PHP legado e como ficou no PHP moderno.

PHP 5.x — cálculo de desconto verboso 

<?php
// Sem tipos, sem strict_types
function calcularDesconto($total, $tipoUsuario) {
    if ($tipoUsuario == 'vip' && $total >= 500) {
        return $total * 0.25;
    } else if ($tipoUsuario == 'vip') {
        return $total * 0.15;
    } else if ($total >= 1000) {
        return $total * 0.20;
    } else {
        return 0;
    }
}
?>

PHP 8.x — match expression tipado 

<?php
declare(strict_types=1);

function calcularDesconto(int $total, string $tipoUsuario): float {
    return match(true) {
        $tipoUsuario === 'vip' && $total >= 500 => $total * 0.25,
        $tipoUsuario === 'vip' => $total * 0.15,
        $total >= 1000 => $total * 0.20,
        default => 0,
    };
}
?>

PHP 5.x — tratamento de input verboso 

<?php
// Sem filtros modernos, sem null coalescing
if (isset($_GET['page'])) {
    $page = (int) $_GET['page'];
} else {
    $page = 1;
}

if (isset($_GET['limit'])) {
    $limit = (int) $_GET['limit'];
    if ($limit > 100) {
        $limit = 100;
    }
} else {
    $limit = 20;
}

// SQL Injection era comum:
$sql = "SELECT * FROM users WHERE id = " . $_GET['id'];
?>

PHP 8.x — filter_input + null coalescing 

<?php
declare(strict_types=1);

$page = filter_input(INPUT_GET, 'page', FILTER_VALIDATE_INT) ?? 1;
$limit = min(
    filter_input(INPUT_GET, 'limit', FILTER_VALIDATE_INT) ?? 20,
    100
);

// PDO + prepared statements (obrigatório desde PHP 7)
$stmt = $pdo->prepare('SELECT * FROM users WHERE id = :id');
$stmt->execute(['id' => filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT)]);
?>

PHP 5.x — null handling verboso 

<?php
// Null handling verboso
$username = isset($_GET['user']) ? $_GET['user'] : 'guest';

// Encadeamento aninhado
if (isset($_SESSION['user'])) {
    $user = $_SESSION['user'];
} else if (isset($_COOKIE['user'])) {
    $user = $_COOKIE['user'];
} else {
    $user = 'anonymous';
}

// Ordenação complexa
usort($users, function($a, $b) {
    if ($a['age'] == $b['age']) return 0;
    return $a['age'] < $b['age'] ? -1 : 1;
});
?>

PHP 8.x — nullsafe + spaceship + arrow fn 

<?php
// Null coalescing
$username = $_GET['user'] ?? 'guest';

// Encadeamento
$user = $_SESSION['user'] ?? $_COOKIE['user'] ?? 'anonymous';

// Ordenação com spaceship + arrow function
usort($users, fn($a, $b) => $a['age'] <=> $b['age']);

// Nullsafe operator
$city = $user?->address?->city ?? 'São Paulo';
?>

PHP 5.x — erros silenciosos 

<?php
// mysql_query retornava false silenciosamente
$result = mysql_query("SELECT * FROM users");
if (!$result) {
    // Erro difícil de debugar
    echo "Erro: " . mysql_error();
}

// file_get_contents sem try/catch
$content = file_get_contents('https://api.exemplo.com/data');
if ($content === false) {
    echo "Falhou";
}
?>

PHP 8.x — exceções + PDO 

<?php
declare(strict_types=1);

// PDO lança exceções automaticamente
try {
    $stmt = $pdo->query('SELECT * FROM users');
    $users = $stmt->fetchAll(PDO::FETCH_ASSOC);
} catch (PDOException $e) {
    error_log($e->getMessage());
    throw new RuntimeException('Erro ao buscar usuários');
}

// file_get_contents com tratamento moderno
try {
    $content = file_get_contents('https://api.exemplo.com/data');
    if ($content === false) {
        throw new RuntimeException('Falha na requisição');
    }
    $data = json_decode($content, true, flags: JSON_THROW_ON_ERROR);
} catch (RuntimeException | JsonException $e) {
    error_log($e->getMessage());
}
?>

PHP 5.x — DTO verboso 

<?php
class UserDTO {
    private $id;
    private $name;
    private $email;
    private $age;

    public function __construct($id, $name, $email, $age) {
        $this->id = $id;
        $this->name = $name;
        $this->email = $email;
        $this->age = $age;
    }

    public function getId() { return $this->id; }
    public function getName() { return $this->name; }
    public function getEmail() { return $this->email; }
    public function getAge() { return $this->age; }
}
?>

PHP 8.x — constructor promotion + readonly 

<?php
declare(strict_types=1);

readonly class UserDTO {
    public function __construct(
        public int $id,
        public string $name,
        public string $email,
        public int $age,
    ) {}
}

// Uso com named arguments
$user = new UserDTO(
    id: 1,
    name: 'Alisson',
    email: 'alisson@email.com',
    age: 28,
);
?>

O que o PHP 7.0 resolveu

Uma correção de rota histórica — cada gargalo tinha uma resposta.

Performance +100%

Novo motor Zend Engine 3 com OPcache nativo — memória e CPU drasticamente reduzidas.

Tipagem escalar

Type hints para int, float, string e bool — fim dos bugs silenciosos.

Null coalescing

?? simplifica verificações de existência e nulidade.

Spaceship operator

Comparações complexas em uma única linha.

Segurança reforçada

Remoção de mysql_* e reforço em PDO — ambiente mais seguro.

Composer maduro

Ecossistema unificado de pacotes com autoload PSR-4.

Guia prático

Como migrar do PHP legado

Passos essenciais para trazer um projeto antigo para o PHP moderno com segurança.

1. Auditoria inicial

Rode PHPStan ou Psalm na versão atual antes de qualquer mudança. Identifique funções removidas e padrões obsoletos.

# Análise estática em projeto legado
composer require --dev phpstan/phpstan
vendor/bin/phpstan analyse src --level=5

# Buscar funções obsoletas
grep -rn "mysql_query\|ereg\|split(" src/

2. Atualizar dependências

Atualize Composer para 2.x, defina uma versão mínima de PHP e atualize bibliotecas.

{
    "require": {
        "php": "^8.2",
        "ext-pdo": "*",
        "monolog/monolog": "^3.0"
    },
    "config": {
        "platform": {
            "php": "8.2.0"
        }
    }
}

3. Substituir mysql_* por PDO

Migre todas as chamadas antigas para PDO com prepared statements.

<?php
$pdo = new PDO(
    'mysql:host=localhost;dbname=app;charset=utf8mb4',
    $user,
    $pass,
    [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false,
    ]
);

$stmt = $pdo->prepare('SELECT * FROM users WHERE email = :email');
$stmt->execute(['email' => $email]);
?>

4. Testes automatizados

Adicione PHPUnit e escreva testes de caracterização antes de refatorar.

<?php
use PHPUnit\Framework\TestCase;

class CalculadoraTest extends TestCase {
    public function testDescontoVip(): void {
        $result = calcularDesconto(600, 'vip');
        $this->assertEquals(150.0, $result);
    }
}
?>
