PHP 7.0: A Revolução da Performance

Lançado em dezembro de 2015 - 2x mais rápido, menos memória, e recursos que mudaram tudo

Scalar Type Declarations

Agora você pode declarar tipos escalares (int, float, string, bool) nos parâmetros e retornos de funções.

<?php
declare(strict_types=1); // Modo estrito (opcional)

// Declaração de tipos escalares
function sum(int $a, int $b): int {
    return $a + $b;
}

function greet(string $name): string {
    return "Hello, $name!";
}

function divide(float $dividend, float $divisor): float {
    return $dividend / $divisor;
}

function isAdult(int $age): bool {
    return $age >= 18;
}

// Exemplos de uso
echo sum(10, 20);        // 30
echo greet("Alisson");   // Hello, Alisson!
echo divide(15.5, 2.5);  // 6.2
var_dump(isAdult(25));   // bool(true)

// Com strict_types=1, isso causaria erro:
// sum("10", "20"); // TypeError
?>

PHP 7.0+

Null Coalescing Operator (??)

Sintaxe elegante para verificar se uma variável existe e não é nula.

<?php
// Antes do PHP 7
$username = isset($_GET['user']) ? $_GET['user'] : 'guest';

// Com PHP 7 - Null Coalescing Operator
$username = $_GET['user'] ?? 'guest';

// Exemplos práticos
$config = [
    'database' => 'mysql',
    'host' => 'localhost'
];

$database = $config['database'] ?? 'sqlite';
$password = $config['password'] ?? 'default_password';
$port = $config['port'] ?? 3306;

// Encadeamento de operadores
$user = $_SESSION['user'] ?? $_COOKIE['user'] ?? 'anonymous';

// Com arrays aninhados
$city = $_POST['user']['address']['city'] ?? 'São Paulo';

echo "Database: $database\n";      // mysql
echo "Password: $password\n";      // default_password
echo "User: $user\n";              // anonymous
?>
PHP 7.0+

Spaceship Operator (<=>)

Comparação combinada: retorna -1, 0 ou 1.

<?php
// Spaceship operator retorna:
// -1 se $a < $b
// 0 se $a == $b
// 1 se $a > $b

echo 1 <=> 1;  // 0
echo 1 <=> 2;  // -1
echo 2 <=> 1;  // 1

// Exemplo prático: ordenação de arrays
$users = [
    ['name' => 'Alisson', 'age' => 28],
    ['name' => 'Bruno', 'age' => 32],
    ['name' => 'Carla', 'age' => 25],
];

// Ordenar por idade usando spaceship
usort($users, function($a, $b) {
    return $a['age'] <=> $b['age'];
});

// Ordenação múltipla (primeiro por idade, depois por nome)
usort($users, function($a, $b) {
    return $a['age'] <=> $b['age'] ?: $a['name'] <=> $b['name'];
});

print_r($users);
?>

JIT (Just-In-Time Compilation)

Compilação em tempo real que pode aumentar drasticamente a performance em operações CPU-intensive.

<?php
// JIT melhora dramaticamente loops pesados e cálculos matemáticos
function fibonacci(int $n): int {
    return match($n) {
        0, 1 => $n,
        default => fibonacci($n-1) + fibonacci($n-2)
    };
}

function calcularPrimos(int $limite): array {
    $primos = [];
    for ($i = 2; $i <= $limite; $i++) {
        $ePrimo = true;
        for ($j = 2; $j <= sqrt($i); $j++) {
            if ($i % $j == 0) {
                $ePrimo = false;
                break;
            }
        }
        if ($ePrimo) $primos[] = $i;
    }
    return $primos;
}

// Com JIT ativado, essas operações são muito mais rápidas
$inicio = microtime(true);
$fib = fibonacci(35);
$primos = calcularPrimos(100000);
$tempo = microtime(true) - $inicio;

echo "Fibonacci(35): $fib\n";
echo "Primos encontrados: " . count($primos) . "\n";
echo "Tempo com JIT: {$tempo} segundos\n";

// Para ativar JIT no php.ini:
// opcache.jit = tracing
// opcache.jit_buffer_size = 100M
?>

Attributes (Annotations)

Metadados nativos substituindo docblocks - mais rápido, tipado e integrado à linguagem.

<?php
// Definindo Attributes customizados
#[Attribute(Attribute::TARGET_METHOD | Attribute::TARGET_CLASS)]
class Route {
    public function __construct(
        public string $path, 
        public string $method = 'GET'
    ) {}
}

#[Attribute(Attribute::TARGET_PROPERTY)]
class Validate {
    public function __construct(
        public string $rule, 
        public ?string $message = null
    ) {}
}

#[Attribute(Attribute::TARGET_METHOD)]
class Auth {
    public function __construct(public array $roles = []) {}
}

// Usando os Attributes
#[Route('/api/users', 'GET')]
class UserController {
    #[Validate('required|email')]
    private string $email;
    
    #[Auth(['admin', 'editor'])]
    #[Route('/admin/dashboard', 'POST')]
    public function adminPanel(): string {
        return "Acesso autorizado";
    }
}

// Lendo Attributes via Reflection
$reflection = new ReflectionMethod(UserController::class, 'adminPanel');
$routeAttr = $reflection->getAttributes(Route::class)[0] ?? null;
$authAttr = $reflection->getAttributes(Auth::class)[0] ?? null;

if ($routeAttr) {
    $route = $routeAttr->newInstance();
    echo "Rota: {$route->path} [{$route->method}]\n";
}
if ($authAttr) {
    $auth = $authAttr->newInstance();
    echo "Roles: " . implode(', ', $auth->roles) . "\n";
}
?>

class OldUser {

        $this->email = $email;
        $this->age = $age;

    public function __construct(
        private string $name,
        private string $email,
        private int $age,

        private readonly string $id = '', // readonly desde 8.1

Enums (PHP 8.1)

Enums nativos com suporte a métodos, valores escalares e type safety.

<?php
// Basic Enum
enum Status {
    case PENDING;
    case APPROVED;
    case REJECTED;
}

// Backed Enum (com valores)
enum PaymentStatus: string {
    case PENDING = 'pending';
    case PAID = 'paid';
    case FAILED = 'failed';
    case REFUNDED = 'refunded';
    
    public function label(): string {
        return match($this) {
            self::PENDING => 'Aguardando pagamento',
            self::PAID => 'Pago com sucesso',
            self::FAILED => 'Falha no pagamento',
            self::REFUNDED => 'Estornado',
        };
    }
    
    public function canCancel(): bool {
        return $this === self::PENDING;
    }
}

// Enum com métodos complexos
enum UserRole: int {
    case GUEST = 0;
    case USER = 1;
    case MODERATOR = 5;
    case ADMIN = 10;
    
    public function permissions(): array {
        return match($this) {
            self::GUEST => ['view'],
            self::USER => ['view', 'comment'],
            self::MODERATOR => ['view', 'comment', 'edit', 'delete'],
            self::ADMIN => ['view', 'comment', 'edit', 'delete', 'manage_users', 'settings'],
        };
    }
    
    public static function fromName(string $name): ?self {
        return match(strtolower($name)) {
            'guest' => self::GUEST,
            'user' => self::USER,
            'moderator' => self::MODERATOR,
            'admin' => self::ADMIN,
            default => null,
        };
    }
}

// Uso prático
$payment = PaymentStatus::PAID;
echo $payment->label(); // "Pago com sucesso"
echo $payment->value;    // "paid"

$role = UserRole::ADMIN;
$permissions = $role->permissions();
print_r($permissions);
?>

Match Expression (PHP 8.0)

Substituto mais seguro e expressivo para switch, sem coerção de tipos.

<?php
// Match vs Switch
function getStatusMessage(string $status): string {
    return match($status) {
        'pending' => 'Aguardando processamento',
        'approved' => 'Aprovado!',
        'rejected' => 'Infelizmente foi rejeitado',
        'processing' => 'Processando...',
        default => 'Status desconhecido',
    };
}

// Match com condições mais complexas
function calculateDiscount(int $total, string $userType): float {
    return match(true) {
        $userType === 'vip' && $total >= 500 => $total * 0.25,
        $userType === 'vip' => $total * 0.15,
        $total >= 1000 => $total * 0.20,
        $total >= 500 => $total * 0.10,
        $total >= 100 => $total * 0.05,
        default => 0,
    };
}

// Match com enums
function handlePayment(PaymentStatus $status): string {
    return match($status) {
        PaymentStatus::PENDING => 'Pagamento pendente',
        PaymentStatus::PAID => 'Pagamento confirmado',
        PaymentStatus::FAILED => 'Falha, tente novamente',
        PaymentStatus::REFUNDED => 'Valor estornado',
    };
}

// Match permite múltiplos casos
function getDayType(int $day): string {
    return match($day) {
        1, 7 => 'Final de semana',
        2, 3, 4, 5, 6 => 'Dia útil',
        default => 'Dia inválido',
    };
}
?>

Fibers (PHP 8.1) - Concorrência leve

Permite pausar e retomar execuções, ideal para I/O não bloqueante.

<?php
// Fiber básico
$fiber = new Fiber(function(): void {
    echo "Iniciando Fiber...\n";
    $value = Fiber::suspend('Pausado');
    echo "Retomado com valor: $value\n";
});

$result = $fiber->start();
echo "Fiber pausado com: $result\n";
$fiber->resume('Dados processados');

// Exemplo prático: simulação de tasks concorrentes
function task1(): void {
    echo "Task 1: Início\n";
    Fiber::suspend();
    echo "Task 1: Finalizada\n";
}

function task2(): void {
    echo "Task 2: Processando...\n";
    Fiber::suspend();
    echo "Task 2: Concluída!\n";
}

$fibers = [
    new Fiber('task1'),
    new Fiber('task2'),
];

foreach ($fibers as $fiber) {
    $fiber->start();
}

// Continuar todas após alguma condição
foreach ($fibers as $fiber) {
    if (!$fiber->isTerminated()) {
        $fiber->resume();
    }
}

// Exemplo com yield-like behavior
function fetchDataFromAPI(string $url) {
    return new Fiber(function() use ($url) {
        echo "Buscando $url...\n";
        Fiber::suspend("Processando requisição");
        return "Dados de $url";
    });
}

$apiFiber = fetchDataFromAPI("https://api.exemplo.com/users");
echo $apiFiber->start(); // "Processando requisição"
$result = $apiFiber->resume();
echo $result; // "Dados de https://api.exemplo.com/users"
?>

Readonly Classes (PHP 8.2)

Classes imutáveis - todas as propriedades se tornam readonly automaticamente.

<?php
// Classe readonly (todas propriedades imutáveis)
readonly class Configuration {
    public function __construct(
        public string $database,
        public string $host,
        public int $port,
        public bool $debug = false
    ) {}
}

readonly class Address {
    public function __construct(
        public string $street,
        public string $city,
        public string $zipCode,
        public ?string $complement = null
    ) {}
}

// Tentativa de modificação causará erro
$config = new Configuration(
    database: 'mysql',
    host: 'localhost', 
    port: 3306,
    debug: true
);

// $config->port = 5432; // Error: Cannot modify readonly property

// Para modificar, criar nova instância
$newConfig = new Configuration(
    database: $config->database,
    host: $config->host,
    port: 5432,
    debug: $config->debug
);

readonly class UserProfile {
    public function __construct(
        public string $name,
        public string $email,
        public \DateTimeImmutable $createdAt,
        private array $metadata = []
    ) {}
    
    // Métodos permitem lógica, mas não modificam propriedades
    public function getMetadata(): array {
        return $this->metadata;
    }
}
?>

Melhorias na Manipulação de JSON (PHP 8.3)

Novas constantes e funções para tratar erros de JSON de forma mais elegante.

<?php
// Nova função json_validate() no PHP 8.3
$jsonString = '{"name": "Alisson", "age": 28}';
$invalidJson = '{"name": "Alisson", age: 28}'; // inválido (age sem aspas)

if (json_validate($jsonString)) {
    echo "JSON válido!\n";
    $data = json_decode($jsonString, true);
} else {
    echo "JSON inválido: " . json_last_error_msg() . "\n";
}

// Constantes de erro mais detalhadas
const JSON_ERROR_NONE = 0;
const JSON_ERROR_DEPTH = 1;
const JSON_ERROR_STATE_MISMATCH = 2;
const JSON_ERROR_CTRL_CHAR = 3;
const JSON_ERROR_SYNTAX = 4;
// ... e muitas outras

// Função para safe decode
function safeJsonDecode(string $json, bool $assoc = true): array|object|null {
    if (!json_validate($json)) {
        throw new InvalidArgumentException('JSON inválido: ' . json_last_error_msg());
    }
    return json_decode($json, $assoc);
}

// Exemplo prático
try {
    $result = safeJsonDecode('{"data": "teste"}');
    print_r($result);
} catch (InvalidArgumentException $e) {
    echo "Erro: " . $e->getMessage();
}
?>

Property Hooks (PHP 8.4 Preview)

Hooks nativos para propriedades - get/set customizados sem métodos auxiliares.

<?php
// PHP 8.4 - Property Hooks (em desenvolvimento)
class User {
    public function __construct(
        private string $name,
        private int $age
    ) {}
    
    public string $fullName {
        get => $this->name;
        set {
            $this->name = strtoupper($value);
        }
    }
    
    public int $age {
        get => $this->age;
        set {
            if ($value < 0 || $value > 150) {
                throw new InvalidArgumentException("Idade inválida");
            }
            $this->age = $value;
        }
    }
    
    public string $displayName {
        get => "{$this->name} ({$this->age} anos)";
    }
}

$user = new User("alisson", 28);
echo $user->displayName; // "alisson (28 anos)"
$user->fullName = "João Silva";
echo $user->fullName; // "JOÃO SILVA"
?>
