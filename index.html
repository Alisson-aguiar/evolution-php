PHP antigo: as dores que nos trouxeram até aqui

Antes do PHP 7, desenvolver era um exercício de paciência e gambiarras.

O PHP 5.x foi responsável por colocar milhões de sites no ar. Mas também trouxe uma série de limitações que tornavam o código difícil de manter, lento e inseguro. Conhecer esses gargalos é essencial para entender por que o PHP 7.0 foi uma revolução.

Performance baixa

Cada requisição consumia muita memória e CPU. Frameworks populares eram pesados e lentos.

Sem tipagem forte

Tipos eram dinâmicos demais, sem type hints escalares. Bugs silenciosos eram comuns.

Erros silenciosos

Funções retornavam false ao invés de lançar exceções. Difícil diagnosticar.

Sintaxe verbosa

Faltavam recursos modernos: null coalescing, spaceship, arrow functions.

Segurança fraca

Muitas funções descontinuadas, riscos de SQL Injection e XSS sem ferramentas nativas.

Gerenciamento de dependências

PEAR era limitado. O Composer ainda dava seus primeiros passos, mas o ecossistema era fragmentado.

PHP 7.0 · 2015

A Revolução da Performance

PHP 7.0 foi um divisor de águas: 2x mais rápido, menos memória e uma linguagem muito mais expressiva.

PHP 7.0 · O renascimento

Dezembro de 2015 — a versão que salvou o PHP.

Scalar Type Declarations

Tipagem forte para parâmetros escalares e retornos de função — fim dos bugs silenciosos.

<?php
declare(strict_types=1);

function sum(int $a, int $b): int {
    return $a + $b;
}

function greet(string $name): string {
    return "Hello, $name!";
}

echo sum(10, 20);       // 30
echo greet("Alisson");  // Hello, Alisson!
?>
PHP 7.0+

Return Type Declarations

Funções garantem o tipo de retorno — contratos explícitos e código autodocumentado.

<?php
class User {
    public function __construct(
        private string $name,
        private int $age
    ) {}

    public function getName(): string { return $this->name; }
    public function getAge(): int { return $this->age; }
    public function toArray(): array {
        return ['name' => $this->name, 'age' => $this->age];
    }
}
?>
PHP 7.0+

Null Coalescing Operator (??)

Fallback elegante para variáveis nulas — fim do ternário duplo.

<?php
// Antes
$name = isset($_GET['user']) ? $_GET['user'] : 'guest';

// Depois
$name = $_GET['user'] ?? 'guest';

// Encadeamento
$user = $_SESSION['user'] ?? $_COOKIE['user'] ?? 'anonymous';
?>
PHP 7.0+

Spaceship Operator (<=>)

Comparação em três vias: -1, 0 ou 1 — perfeito para ordenação.

<?php
echo 1 <=> 1;  // 0
echo 1 <=> 2;  // -1
echo 2 <=> 1;  // 1

$users = [
    ['name' => 'Alisson', 'age' => 28],
    ['name' => 'Bruno', 'age' => 32],
];
usort($users, fn($a, $b) => $a['age'] <=> $b['age']);
?>
PHP 7.0+

Constant Arrays

Arrays como constantes globais — configurações centralizadas e imutáveis.

<?php
define('COLORS', ['red', 'green', 'blue']);
const STATUS_CODES = [
    200 => 'OK',
    404 => 'Not Found',
];

echo COLORS[0];       // red
echo STATUS_CODES[200]; // OK
?>

JIT (Just-In-Time)

Compilação em tempo real que acelera drasticamente operações matemáticas.

<?php
function fibonacci(int $n): int {
    return match($n) {
        0, 1 => $n,
        default => fibonacci($n-1) + fibonacci($n-2)
    };
}

$inicio = microtime(true);
echo fibonacci(35);
echo microtime(true) - $inicio;

// php.ini:
// opcache.jit = tracing
// opcache.jit_buffer_size = 100M
?>
PHP 8.0+

Attributes

Metadados nativos que substituem docblocks — mais rápido e tipado.

<?php
#[Attribute(Attribute::TARGET_METHOD)]
class Route {
    public function __construct(
        public string $path,
        public string $method = 'GET'
    ) {}
}

class UserController {
    #[Route('/api/users', 'GET')]
    public function list(): array { return []; }
}
?>
PHP 8.0+

Constructor Property Promotion

Declare propriedades direto no construtor — 70% menos boilerplate.

<?php
class User {
    public function __construct(
        private string $name,
        private string $email,
        private int $age,
        private readonly string $id = ''
    ) {}
}

$user = new User(
    name: "Alisson",
    email: "alisson@email.com",
    age: 28
);
?>
PHP 8.0+

Enums nativos

Enums type-safe com métodos e valores escalares.

<?php
enum PaymentStatus: string {
    case PENDING = 'pending';
    case PAID = 'paid';
    case FAILED = 'failed';

    public function label(): string {
        return match($this) {
            self::PENDING => 'Aguardando',
            self::PAID => 'Pago',
            self::FAILED => 'Falhou',
        };
    }
}

echo PaymentStatus::PAID->label(); // Pago
?>
PHP 8.1+

Match Expression

Substitui o switch sem coerção de tipos, com retorno obrigatório.

<?php
function calculateDiscount(int $total): float {
    return match(true) {
        $total >= 1000 => $total * 0.20,
        $total >= 500  => $total * 0.10,
        $total >= 100  => $total * 0.05,
        default        => 0,
    };
}
?>
PHP 8.0+

Fibers

Concorrência leve para tarefas de I/O não bloqueante.

<?php
$fiber = new Fiber(function(): void {
    echo "Iniciando...\n";
    $value = Fiber::suspend('Pausado');
    echo "Retomado com: $value\n";
});

echo $fiber->start();
$fiber->resume('Dados');
?>
PHP 8.1+

Readonly Classes

Todas as propriedades viram imutáveis automaticamente.

<?php
readonly class Config {
    public function __construct(
        public string $database,
        public string $host,
        public int $port
    ) {}
}

$config = new Config(database: 'mysql', host: 'localhost', port: 3306);
// $config->port = 5432; // Error!
?>

json_validate() nativo

Validação de JSON direta, sem precisar decodificar.

<?php
$json = '{"name": "Alisson", "age": 28}';

if (json_validate($json)) {
    echo "JSON válido!";
    $data = json_decode($json, true);
}
?>
